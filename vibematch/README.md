# Вайбматч 🎲

Прототип мобильного приложения для подбора занятия «прямо сейчас» —
свайп-карточки в стиле Tinder для фильмов, мест, скидок, книг и игр.

## Что внутри

- **Свайп-карточки** — влево «нет», вправо «да», вверх «на потом», + кнопка undo
- **Реальные данные** — места рядом из OpenStreetMap, игры и скидки из Steam,
  фильмы из TMDB, книги из Google Books / Open Library (см. «Источники данных»)
- **Подбор под контекст** — карточки ранжируются по настроению, компании, времени,
  жанрам, погоде, времени суток, расстоянию, часам работы и прошлым свайпам
- **Геолокация и реальная погода** — Open-Meteo API (без ключа), погода влияет на подборку
- **Карта рядом** — реальные расстояния по координатам (Haversine)
- **AI-подсказки** — каждые 3 свайпа Claude советует что попробовать (через прокси)
- **Совместный режим** — два человека свайпают, находится пересечение
- **Статистика, сохранённые с заметками, настройки, «Удиви меня»**

## Стек

Vite + React + TypeScript. Без тяжёлых зависимостей — стили инлайновые,
анимации на CSS.

## Запуск

```bash
npm install
```

Реальные карточки и AI-подсказки идут через локальный сервер
(`server/proxy.mjs`), чтобы ключи **не попадали в браузер**.

1. Скопируй `.env.example` в `.env` и заполни ключи (все необязательные):

   ```
   ANTHROPIC_API_KEY=sk-ant-...   # AI-подсказки
   TMDB_API_KEY=...               # фильмы
   GOOGLE_BOOKS_API_KEY=...       # книги на русском (иначе Open Library)
   ```

2. Запусти сервер и фронтенд вместе:

   ```bash
   npm run dev:all
   ```

   Либо в двух терминалах: `npm run server` и `npm run dev`.

Сервер слушает порт 8787, Vite проксирует на него запросы `/api/*`
(см. `vite.config.ts`). Если запустить только `npm run dev` без сервера,
приложение покажет встроенную подборку фильмов, книг и игр, а мест рядом не будет.

## Источники данных

| Категория | Источник | Ключ | Без ключа |
|---|---|---|---|
| Места рядом | OpenStreetMap (Overpass API) | не нужен | — |
| Игры | Steam + SteamSpy (популярное за 2 недели, ≥85% положительных отзывов) | не нужен | — |
| Скидки | Steam (текущие специальные предложения, цены в рублях) | не нужен | — |
| Фильмы | TMDB (тренды недели + высоко оценённые, на русском) | `TMDB_API_KEY` | встроенная подборка |
| Книги | Google Books (на русском) | `GOOGLE_BOOKS_API_KEY` | Open Library |
| Погода | Open-Meteo | не нужен | — |

Ключ TMDB бесплатный: https://www.themoviedb.org/settings/api (подходит и
API Key v3, и Read Access Token v4). Ответы кэшируются на сервере (места — 6 ч,
Steam — 3 ч, фильмы — 6 ч, книги — 12 ч). Статус каждого источника виден
в приложении: «Ещё» → «Источники данных».

> ⚠️ Никогда не клади ключ в код фронтенда или в переменные `VITE_*` —
> они попадают в бандл и видны всем. Ключ читается только сервером.

## Структура

```
src/
  data/        — встроенная подборка, настроения, погода
  types/       — TypeScript-типы
  lib/         — хелперы (расстояния, WMO-коды, часы работы, ранжирование, AI)
  hooks/       — useGeoWeather (геолокация + погода), useCards (загрузка карточек)
  components/  — переиспользуемые: NavBar, Toast, ui (Glow, Tag)
  screens/     — экраны: Splash, Onboarding, Swipe, Match,
                 Saved, Stats, Map, Settings, Coop, SurpriseModal
  App.tsx      — оркестратор состояния и роутинг между экранами
server/
  proxy.mjs    — локальный сервер: /api/cards и /api/ai-tip (без зависимостей, Node 18+)
  content.mjs  — загрузка и нормализация данных из OSM, Steam, TMDB, книг
```

## Работа в Claude Code

Открой эту папку и запусти `claude`. Дальше можно давать задачи обычным
текстом — например «добавь время суток как фактор подбора» или
«подключи TMDB для фильмов». Claude Code сам отредактирует нужные файлы.
